How an app checks a key

Send a POST request with the key and a stable device id. A rejected key returns ok false with a reason.


            

          
Possible answers

          

            
ok true
Key is valid. Includes plan, expires_at, days_left and lifetime.

            
invalid_key
The key does not exist.

            
expired / revoked
The key can no longer be used.

            
device_limit
The key is already bound to the maximum number of devices.
